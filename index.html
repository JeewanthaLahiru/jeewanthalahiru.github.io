What I Do

Gameplay Programming in C++

I build core gameplay systems such as player controls, interaction logic, inventory, and game rules in Unreal Engine C++, using UCLASS, UPROPERTY, and UFUNCTION reflection to expose clean, well-structured APIs to Blueprints for designers.

UI/HUD Programming

I implement UI and HUD systems with C++ base widget classes and UMG, binding widgets to gameplay data through delegates and event-driven updates so interfaces stay responsive, usable, and decoupled from game logic.

Physics, Vehicle and Movement Systems

I develop character, vehicle, and drone movement in C++ by extending Unreal's movement and physics components, handling collision, forces, and custom movement modes to achieve realistic, predictable behaviour in real-time simulations.

Simulation and Systems Integration

I integrate Unreal Engine with external systems in C++, such as connecting a drone simulation to the PX4 flight controller over MAVLink for bidirectional exchange of telemetry, sensor data, and flight-control commands.

Custom C++ Plugins and Modules

I design and develop custom Unreal Engine plugins and modules in C++ to extend engine functionality, wrap third-party libraries, and package reusable features that can be shared cleanly across projects.

AI Programming

I develop NPC, animal, and vehicle AI using C++ AI Controllers, custom Behavior Tree tasks, services, and decorators, along with Blackboards and navigation, enabling dynamic decision-making and responsive behaviour.

Character and Animation Integration

I integrate characters and animations using C++ AnimInstance classes, animation blueprints, state machines, montages, notifies, and inverse kinematics (IK), keeping animation tightly synchronized with gameplay state.

Software Architecture and Data-Driven Design

I apply object-oriented design and modern C++ practices to build modular, reusable components, using data assets, data tables, and configuration-driven systems to keep large codebases flexible and maintainable.

Networking and Multiplayer

I implement networked gameplay in C++ using Unreal's replication system, replicated properties, RPCs, and authoritative client-server logic to keep game state synchronized and reliable.

Optimization, Profiling and Debugging

I profile and optimize C++ systems using Unreal Insights, stat commands, and debuggers, identifying bottlenecks, reducing tick and memory overhead, and fixing issues to ensure stable real-time performance.
