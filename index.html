What I Do

Gameplay Programming

I develop core gameplay mechanics such as player controls, combat systems, inventory, and interaction logic using Blueprints and C++ to ensure a responsive and engaging player experience.

UI/HUD Programming

I design and implement responsive UI and HUD elements using Unreal Engine's UMG system, creating intuitive menus, in-game displays, and interactive widgets that are seamlessly integrated with gameplay logic through Blueprints and C++.

Physics and Movement Systems

I implement realistic physics and movement systems by configuring character and vehicle components, customizing collision and physical interactions, and fine-tuning movement behavior using Unreal Engine's built-in physics tools and components.

Level Scripting

I design and implement interactive level elements and gameplay events by scripting with Level Blueprints and Blueprint Interfaces, enabling seamless player interactions and dynamic environments in Unreal Engine.

Custom Plugin Creation

I design and develop custom Unreal Engine plugins using C++ to extend engine functionality, automate workflows, and add specialized features tailored to project needs.

NPC AI Development

I develop intelligent NPC behaviors by creating AI Controllers, Behavior Trees, and Blackboards in Unreal Engine, enabling dynamic decision-making, pathfinding, and responsive interactions within the game world.

Character and Animation Integration

I integrate characters and animations by setting up skeletal meshes, configuring animation blueprints and state machines, and synchronizing movement with gameplay using montages, notifies, and inverse kinematics (IK) in Unreal Engine.

Particle Effects and VFX

I create and integrate dynamic particle effects and visual effects using Unreal Engine's Niagara system, designing impactful VFX that enhance gameplay feedback and immersion.

Networking and Multiplayer

I develop and optimize networking and multiplayer systems by implementing replication, client-server communication, and synchronization of game states to ensure smooth and reliable online gameplay experiences in Unreal Engine.

Optimization and Profiling

I perform optimization and profiling by analyzing performance bottlenecks using Unreal Engine's tools, then refining code, assets, and systems to ensure smooth and efficient gameplay across target platforms.
